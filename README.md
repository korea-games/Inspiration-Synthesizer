# Inspiration Synthesizer

🎹 A pixel-style synthesizer in your browser. Press **✦ 영감!** to get a new sound, chords and melody.

▶ **Play:** https://korea-games.github.io/Inspiration-Synthesizer/

A single static `index.html` with no server needed.
